# 🎨 Wallpaper Studio

> پلتفرم تغییر والپیپر واقعی موبایل با Next.js — پیش‌نمایش زنده، آیکون‌های واقعی و ذخیره تنظیمات

## ✨ ویژگی‌ها

- 🔒 **والپیپر جداگانه** برای صفحه قفل و صفحه اصلی
- 📱 **شبیه‌ساز موبایل واقعی** با Dynamic Island و Status Bar
- 🎯 **آیکون‌های واقعی** Google, Chrome, YouTube, Instagram, WhatsApp و ...
- 💾 **ذخیره خودکار** تنظیمات در localStorage
- 🎬 **لودینگ سه‌بعدی** با انیمیشن مکعب چرخان
- 📐 **کاملاً ریسپانسیو** — مقیاس خودکار گوشی در تمام سایزها
- ⚡ **Native Bridge** — تغییر واقعی والپیپر در اپ اندروید (Capacitor)
- 🌐 **حالت وب** — دانلود والپیپر بهینه‌شده بدون نیاز به نصب

## 🛠️ تکنولوژی‌ها

| بخش | تکنولوژی |
|-----|----------|
| فریمورک | Next.js 16 (App Router + Turbopack) |
| زبان | TypeScript |
| استایل | Tailwind CSS |
| انیمیشن | Framer Motion |
| آیکون‌ها | Lucide React + SVG سفارشی |
| Native | Capacitor (Android) |
| هاستینگ | Netlify |

```bash
# کلون ریپازیتوری

cd wallpaper-studio
